# 🤖 X 评论机器人屏蔽器 (X Comment Bot Blocker)

油猴(Tampermonkey)用户脚本:在 x.com 推文评论区,**选取一条 bot 评论作为模板**或**抓取一个 bot 账号**,一键扫描全部评论,对**用户名命中 / 文本相似 / 评论含关键词**的账号自动屏蔽。

- **v0.14.2** · 纯本地运行 · **数据全量可导出**(JSON 文件 / 文本 / Gist 同步,不锁定在浏览器)
- 内置 91 条高频特征规则,一键加载
- 数据与脚本分离:JSON 数据文件 + Gist 远程同步 + 本地 GM 持久化
- **屏蔽记录(blocklog)**:每次屏蔽留痕,误伤可追溯、可导出、可一键跳主页解封

## ✨ 特性

| 特性 | 说明 |
|---|---|
| **三维匹配** | 用户名(昵称/@handle)· 模板相似度 · 评论关键词,任一命中即处理 |
| **模板驱动** | 点击任意 bot 评论即成为匹配样本,动态维护模板库(增删改) |
| **高频词挖掘** | 已确认账号语料自动提炼高频特征(词频条形图可视化,点击入名单) |
| **防误伤设计** | 评论关键词独立列表、相似度阈值可调、仅标记(试运行)模式、白名单、逐个确认 |
| **防风控** | 屏蔽间隔可调(默认 1.2s)、扫描轮数上限、闲置自动停止、屏蔽结果验证 |
| **屏蔽记录** | 每次屏蔽留痕(昵称/handle/时间/命中原因),按账号去重、上限 300 条;可导出、跳主页解封、加白名单防重锁 |
| **数据导出** | 全量 JSON / blocklog.json / 文本 / 日志,全部可导出;Gist 远程同步跨设备 |
| **界面分层** | 主界面轻量操作 + 五 Tab 设置页 + 收起为停靠圆点 + 护眼浅色主题 + 完整操作反馈 |

## 🧩 功能详解与实现依据

| 功能 | 实现要点 | 依据(为什么这么做) |
|---|---|---|
| **三维匹配** | 用户名(名单)+ 文本相似度(模板)+ 评论关键词,任一命中即处理 | 单一信号必然漏杀(新句式、改名号)或误伤;三维互补覆盖 bot 的主要特征维度,精度靠阈值与白名单收敛 |
| **相似度算法** | 归一化(去 URL/@提及/#话题/emoji/标点/零宽字符)→ 三信号取最高:字符 bigram Jaccard · Levenshtein 编辑距离比 · 包含匹配 | bot 文案变体多(同音字、随机码、拼接),任何单一算法都不稳:Jaccard 对中日英通用,Levenshtein 容忍小差异,包含匹配抓住"短模板被长评论完整包含" |
| **评论关键词独立列表** | 匹配源 = 内置低风险词(排除日常常见词)+ 自定义列表,与用户名名单完全独立 | 名单包含大量普通词(高中/免费/学生),直接匹配评论文本必然误伤正常讨论;分离后普通词只用于匹配用户名 |
| **模板驱动** | 点击任意评论即入库,归一化后精确去重 | 同一 bot 团伙复用同一批文案;以"样本"代替"穷举关键词",新句式也能靠相似度命中 |
| **高频词挖掘** | 从语料(已确认垃圾账号)提取英文词/数字串/CJK bigram,出现于 ≥2 个账号才建议 | 单账号特征不可靠;≥2 账号共现才是团伙特征;人工点击确认后才入名单,防止特征自动扩散造成误伤 |
| **UI 自动化屏蔽** | 点击 … 菜单 → 定位 Block 菜单项(图标 path / data-testid / 文本三重 fallback)→ 确认弹窗 → 验证推文从 DOM 移除 | 不调用内部 GraphQL API(降低 ToS 风险、无需令牌);以 DOM 效果验证成功,未确认不计入统计 |
| **防风控** | 屏蔽间隔 1.2s(可调)、扫描轮数上限、闲置自动停止、建议每天 <100 个 | X 对高频操作限流;模拟真人操作节奏,所有节奏参数均暴露给用户调节 |
| **防误伤** | 仅标记模式、白名单优先于一切规则、推文作者保护、逐个确认、阈值滑块 | 文本相似 ≠ 语义;所有破坏性动作前都有降级路径(试运行)与确认机制 |
| **屏蔽记录 blocklog** | `{h 手柄, n 昵称, t 时间, r 命中原因}`,按 handle 去重、上限 300 条,可导出/同步 | 误伤必须可追溯:知道"屏蔽了谁、为什么";配合 🏠 跳主页解封、✓ 加白名单防止重扫再锁 |
| **数据三层分离** | 内置 BUILTIN(随脚本发布)/ Gist(私有动态)/ GM 存储(运行时合并) | 规则迭代频率远高于代码;公开仓库只放公开规则,个人数据(语料/名单)留在本地与私有 Gist |
| **全量导出** | 下载 JSON(全量含屏蔽记录)/ blocklog.json / 导出文本 / 导出模板 / 导出日志 / Gist 同步 | 数据主权:用户数据不锁定在浏览器,可备份、迁移、跨设备恢复、交接协作 |
| **操作反馈** | 扫描进行中/完成通知(3s 自动消失)、禁用按钮悬停与点击提示原因、日志未读角标 | 可用性:隐形通知条不拦截点击(pointer-events),禁用按钮必须解释原因而非无响应 |
| **护眼浅色主题** | 米白纸底 + 低饱和绿主色 + 柔和红/琥珀,全部颜色走 CSS 变量 | 长时间使用降低蓝光与视觉刺激;变量化后一处调色全局生效 |

## 🔬 工作原理

### 三维匹配矩阵

| 维度 | 匹配对象 | 规则来源 | 命中示例 |
|---|---|---|---|
| ① 用户名 | 昵称(显示名)+ @handle | 名单条目(包含/正则) | `福利` → 昵称"免费领福利官🎁" |
| ② 模板相似度 | 评论文本 | 模板评论(相似度 ≥ 阈值) | 与模板 85% 相似的新变体 |
| ③ 评论关键词 | 评论文本 | 内置低风险词+自定义列表(可选开关) | 新句式里含"约炮" |

### 扫描流程

```
开始扫描
  │
  ▼
获取评论区容器 → 逐条评论
  │
  ▼
提取: 昵称 / @handle / 文本
  │
  ▼
保护检查(白名单 / 推文作者本人) ──是──► 跳过
  │ 否
  ▼
① 用户名命中? ──是──┐
  │ 否              │
  ▼                 │
② 模板相似度≥阈值? ──┤
  │ 否              │
  ▼                 │
③ 评论含关键词? ────┤ (可选)
  │ 否              │
  ▼                 ▼
跳过           任一命中 → 处理
                   │
                   ▼
        自动屏蔽? 是→ 模拟点击 …→Block→确认 → 验证推文移除
                   │ 否
                   ▼
              仅标记: 红框高亮
                   │
                   ▼
        屏蔽成功 → 写入语料(高频词挖掘≥2账号) + 写入屏蔽记录(blocklog)
                   │
                   ▼
    点击 Show more / 滚动加载 → 无新评论 → 停止 → 二次复核 → 统计
```

### 相似度算法

1. **归一化**:小写、去 URL/@提及/#话题/emoji/标点/零宽字符;
2. **三信号取最高**:字符 bigram Jaccard(中英文通用)· Levenshtein 编辑距离比 · 包含匹配;
3. 短于 4 字符的评论不参与文本判定(防误伤)。

### 屏蔽实现(X UI 自动化)

模拟真人操作路径,不调用内部 GraphQL API:
```
点击 "…" 菜单 → 定位 Block 菜单项(图标 SVG path 特征 / data-testid / 文本 三重 fallback)
→ 点击确认弹窗按钮(优先 confirmationSheetConfirm testid)
→ 验证: 屏蔽成功后推文从 DOM 移除, 未移除则记为"未确认"不计入统计
```
选择器参考仍在维护的 [X_impression_hide](https://github.com/hi2ma-bu4/X_impression_hide),并适配 X DOM 中 handle 一律小写的特性。

### Bot 对抗手段与对策

| Bot 手段 | 对策 |
|---|---|
| 同音字规避(`约炮`→`约萢`/`约泡`/`约pao`) | 内置规则覆盖全变体,支持正则 |
| 评论内插入随机码(`30+的sv体制内老师…`) | 编辑距离容忍小差异 + 无码核心句模板 + 阈值可调 |
| 自动生成用户名(英文名+5位随机数字) | handle 正则(排除生日年份结尾,如 `zhangwei1985` 不误伤) |
| 普通词混入名单(挖掘词误伤正常评论) | 评论关键词独立列表 + 名单只匹配用户名 + 白名单 |

### 数据分层

```
┌─ 内置 BUILTIN(91条) ── 公开/稳定/随脚本发布 ──► 离线兜底 + 基线恢复
├─ Gist(可选) ────────── 私有/动态/你维护 ──────► 主数据源(URL 由用户自行填写, 不内置防泄漏)
└─ 本地 GM 存储 ──────── 运行时合并结果 ────────► 实际生效的名单
```

## 💾 数据导出(重点)

**数据与脚本分离,任何数据都能导出为文件,不锁定在浏览器里:**

| 导出方式 | 内容 | 位置 |
|---|---|---|
| **下载 JSON(全量)** | 模板 / 名单 / 评论关键词 / 屏蔽记录 / 语料,一个文件全带走 | ⚙ 数据 → 数据文件 → [下载 JSON] |
| **导出 blocklog.json** | 仅屏蔽记录(独立备份,便于查看/交接) | ⚙ 数据 → 近期屏蔽记录 → [导出] |
| **导出全部(文本)** | 模板/评论关键词/语料/名单,可发给作者生成补充规则 | ⚙ 设置页 → [导出全部] |
| **导出模板** | 仅模板评论 | 模板 tab → [导出模板] |
| **导出日志** | 本次会话日志(排查 / 生成补充规则) | 主界面日志行 → [导出] |
| **Gist 远程同步** | 全量合并到私有 Gist(跨设备恢复) | ⚙ 数据 → [📡 拉取并合并] |

导入侧同样完整:本地 JSON 文件、文本规则(每行一条,`#` 开头为注释)、Gist 均可**合并去重导入**,不会覆盖已有条目。

## 📖 使用指南

### 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.org/);
2. 添加新脚本,粘贴 `x-comment-bot-blocker.user.js` 内容保存(或导入文件);
3. 打开 x.com,刷新页面,右上角出现悬浮面板(标题栏显示版本号);
4. 脚本支持**自动更新**:已配置 updateURL 指向本仓库 raw 地址,Tampermonkey 每 24h 左右自动检查;也可在管理面板手动"检查更新"。

### 主界面(日常操作)

```
🤖 X Bot 屏蔽器 v0.14.2      ⚙ 🗕
[▶ 扫描] [⏹]  待机   0/0/0 [x]自动
[＋ 选取评论] [＋ 选取用户]
阈值 ●──────── 0.75
日志 ③    ▾   [导出] [清空]
```

- **[▶ 扫描]** 一键扫描;**0/0/0** = 扫描/疑似/封禁(本次);**累计**在设置页数据概览;
- 扫描中 [▶] 禁用但可点击(提示"扫描进行中");待机时 [⏹] 同理(提示"当前没有进行中的扫描");
- **[＋ 选取评论]** → 点击任意 bot 评论 → 成为模板;[＋ 选取用户] → 抓取作者昵称入名单;
- **阈值**:0.75 起步,误伤多调高,漏掉多调低;
- **日志行整行可点**:展开全高日志(只滚日志,统计固定);扫描中折叠时显示未读角标;
- **🗕**:收起为停靠右缘的 🤖 圆点,左键直接扫描、右键恢复主界面;
- **⚠ 刷新页面会清空日志**,导出请先点 [导出]。

### 设置页(⚙,五 Tab)

| Tab | 内容 |
|---|---|
| **模板** | 模板评论列表(增删改、清理无效、导出),列表占满整屏,底部输入框随时添加 |
| **名单** | 用户名名单(增删改、内置 91 条、导入、清空),支持 `/正则/` 条目 |
| **特征词** | 语料统计 + 词频条形图(点击行加入名单)+ 手动添加(不经过挖掘阈值) |
| **数据** | 数据概览(模板/名单/语料/累计封禁/上次同步)+ 下载/导入 JSON + Gist 远程同步 + 近期屏蔽记录(导出/主页解封/白名单) |
| **选项** | 屏蔽行为(逐个确认/包含匹配/评论关键词列表/屏蔽间隔)+ 扫描参数 + 白名单 |

### 推荐工作流

1. **首次**:⚙设置 → 数据 → 拉取 Gist 同步(或点 [内置] 加载 91 条基线);
2. **试运行**:取消勾选"自动屏蔽"跑一轮"仅标记",确认命中质量;
3. 误伤账号加入白名单;名单里过宽的词(如 `快速`/`无偿`/`线下`)及时删除;
4. 确认无误后勾回"自动屏蔽",建议保持屏蔽间隔 ≥1000ms,每天 ≤100 个防风控;
5. **评论关键词匹配**默认关——匹配源为"内置低风险词 + 自定义评论关键词列表",与用户名名单完全独立(名单里的普通词如"高中"/"免费"不会误伤正常评论);自定义列表在 ⚙设置→选项 维护,开启后建议先用仅标记验证。

### 误伤处理流程(屏蔽记录闭环)

```
发现误伤 → ⚙ 数据 → 近期屏蔽记录 → 找到该账号(悬停看命中原因)
  → 🏠 打开对方主页手动解除屏蔽
  → ✓ 加入白名单(下次扫描不再处理, 防止重锁)
  → (可选) [导出] blocklog.json 留档 / 从记录中删除
```

## ⚠️ 风险与对策

| 风险 | 对策 |
|---|---|
| 文本相似 ≠ 语义,批量屏蔽有误伤 | 阈值可调 + 仅标记模式 + 白名单 + 逐个确认 + 屏蔽记录可追溯解封 |
| 快速大批量屏蔽触发 X 风控 | 屏蔽间隔 1.2s(可调)、轮数上限、每天 <100 个 |
| 评论区懒加载扫不全 | 自动滚动 + 自动点击 "Show more replies",无新内容自动停止 |
| X 前端改版导致选择器失效 | 多重 fallback(图标 path / data-testid / 文本) |
| 名单脏数据公开传播 | 内置只含公开规则;脏数据建议留在本地/Gist(secret),勿放 GitHub Pages |
| secret Gist URL 泄漏 | 脚本默认不内置任何数据源 URL,由用户自行填写(secret gist 的 URL 即访问钥匙) |
